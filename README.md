# Roleplay Plugin

多角色代入的场景分析与信息隔离框架，用于 roleplay 场景中的角色认知模拟。

## 功能
- **场景分析**: 根据时间地点和其他补充信息, 推测天气/光照等对角色感知与行为的影响
- **信息隔离**：确保每个角色只能访问其认知边界内的信息
- **并行代入**：多个角色同时独立思考，互不干扰
- **叙事生成**：根据风格配置生成不同风格的叙事文本

## 使用方式

使用 `/roleplay` 命令触发工作流。

## 目录结构约定

```
项目根目录/
├── runtime.yaml           # 当前运行状态（必需）
├── characters/            # 角色定义（必需）
│   └── *.yaml
├── worldview/             # 世界总体设定和大事件记录
│   └── *.yaml
├── location_and_faction/  # 地区和势力设定
│   └── *.yaml
├── others/                # 其他设定文件
│   └── *.yaml
└── records/               # 历史事件记录
    └── *.yaml
```

- `runtime.yaml`：存储当前场景状态、在场角色、环境信息等运行时数据
- `characters/`：存储各角色的定义文件，包括属性、能力、认知、目标等
- `worldview/`：存储世界总体设定（如历史背景、物理法则、魔法体系）和大事件记录
- `location_and_faction/`：存储地区设定（地理、气候、文化）和势力设定（组织、关系）
- `others/`：存储其他杂项设定文件
- `records/`：存储历史事件记录，按场景或章节组织

## 核心概念

### 三层数据语义

1. **L1 Truth Store**：客观真相，只有主控 Agent 可读
2. **L2 Per-Character Access**：角色可触及的客观，由程序派生
3. **L3 Subjective State**：角色主观心智，由 Agent 输出

### 信息隔离铁律

- Agent 不接触 L1 原始对象
- Agent 不共享其他角色的 L2 视图
- GodOnly 知识不进入任何 L2
- 数值翻译为档位后再传入 Agent
