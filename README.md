# Roleplay Plugin

多角色代入的场景分析与信息隔离框架，用于 roleplay 场景中的角色认知模拟。

## 功能
- **场景分析**: 根据时间地点和其他补充信息, 推测天气/光照等对角色感知与行为的影响
- **信息隔离**：确保每个角色只能访问其认知边界内的信息
- **并行代入**：多个角色同时独立思考，互不干扰
- **叙事生成**：根据风格配置生成不同风格的叙事文本

## 使用方式

使用 `/roleplay` 命令触发工作流。

## 核心概念

### 三层数据语义

1. **L1 Truth Store**：客观真相，只有主控 Agent 可读
2. **L2 Per-Character Access**：角色可触及的客观，由程序派生
3. **L3 Subjective State**：角色主观心智，由 Agent 输出

### 信息隔离铁律

- Agent 不接触 L1 原始对象
- Agent 不共享其他角色的 L2 视图
- GodOnly 知识不进入任何 L2
- 数值翻译为档位后再传入 Agent
